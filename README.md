# Marina's Perfect Little Day 💚

A tiny Sims-style birthday game. Walk around a little Toronto condo, complete
six cozy interactions to fill the happiness meter, and unlock the birthday
surprise.

**Play it:** the whole game is a single self-contained file — `docs/index.html`
(built by `tools/build.py`, which inlines every asset as a data URI).

- `game.js` — the whole game (canvas, no dependencies)
- `assets/` — processed sprites (cut, trimmed and downscaled from `art-src/`)
- `art-src/` — original generated key art
- `tools/` — asset pipeline + build scripts

Made with love (and Claude) for Marina's birthday.
